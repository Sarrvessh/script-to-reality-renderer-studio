# Script-to-Reality Renderer Studio

The studio is a light gray page with a narrow white sidebar. Controls sit in grouped rows, the way a system settings list does. The action that moves a project forward is a blue pill. Everything else stays quiet.

Pages are Studio, Library, and Settings. A project moves through Script, Storyboard, Footage, Voice, and Render. Settings holds the dashboard controls: language model, footage keys, picture, sound, captions, script length, and the encoder. Keys are write-only.

The typeface is the system font. There is no display face, no colored rail, and no chart dashboard.
